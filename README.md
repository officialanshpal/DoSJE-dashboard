# DoSJE Project Monitoring & Inspection Platform

A responsive React prototype for the Department of Social Justice & Empowerment project monitoring workflow.

## Run locally

```bash
pnpm install
pnpm dev
```

The project uses React, Vite, Tailwind CSS, Recharts, and Lucide icons. Demo role selection does not require credentials. The mock `api` adapter in `src/App.jsx` exposes async project, alert, and inspection calls; replace it with API requests when wiring a backend.
